Class & Group Manager — ชุดแก้ไขจากโปรเจกต์เดิม
====================================================

ฟีเจอร์ที่แก้ในชุดนี้
- นักเรียนพิมพ์ทักษะของตัวเองได้เอง จะกรอกหรือเว้นว่างก็ได้
- บันทึกทักษะที่พิมพ์เองไว้ในฐานข้อมูลและโหลดกลับมาเมื่อเข้าสู่ระบบครั้งถัดไป
- ป้องกัน JavaScript error จากการเรียก reset() กับค่าที่ไม่มีฟอร์ม
- ล้างข้อมูลฟอร์มหลังออกจากระบบ และสลับหน้าตามบทบาทครู/นักเรียน
- บันทึกรายละเอียดงานเมื่อครูสร้างห้องเรียน
- ย่อ/ซ่อนรายละเอียดห้องเรียนได้โดยกดปุ่มย่อ และเปิดใหม่จากการ์ดห้อง
- แสดงรายชื่อนักเรียนด้วยชื่อเท่านั้น ไม่แสดงรหัสผู้ใช้หรืออีเมล
- เรียงผลกลุ่มตามหมายเลขกลุ่ม และนักเรียนประเมินนักเรียนคนอื่นในผลสุ่มเดียวกันได้ แต่ประเมินตัวเองไม่ได้
- URL ของ CSS/JavaScript มีเวอร์ชันเพื่อช่วยป้องกันแคชไฟล์เก่า

วิธีติดตั้ง
1. สำรองโฟลเดอร์โปรเจกต์เดิมไว้ก่อน
2. แตก ZIP นี้
3. นำไฟล์ index.php, api/index.php, assets/app.js, assets/style.css, schema_check.php และโฟลเดอร์ database ไปใส่ในโฟลเดอร์โปรเจกต์ที่ใช้งานอยู่ โดยคงโครงสร้างโฟลเดอร์
4. สำคัญ: ถ้า config/database.php ของโปรเจกต์เดิมเชื่อมต่อฐานข้อมูล gg ได้อยู่แล้ว ให้เก็บไฟล์เดิมไว้ อย่าเขียนทับด้วย config จาก ZIP
5. เปิด phpMyAdmin เลือกฐานข้อมูล gg แล้วเปิดแท็บ SQL จากนั้นรัน database/migration_2026_10_26.sql หนึ่งครั้ง (สคริปต์ตรวจสอบก่อนว่าคอลัมน์ description มีแล้วหรือยัง และสร้างตารางทักษะที่พิมพ์เองหากยังไม่มี)
6. เปิดเว็บด้วย URL เดิม แล้วกด Ctrl+F5 เพื่อโหลด JavaScript/CSS เวอร์ชันใหม่

ทดสอบหลังติดตั้ง
- เข้าระบบนักเรียน: ช่องทักษะเป็นช่องพิมพ์ ไม่ต้องกรอกก็ได้
- พิมพ์ทักษะแล้วบันทึก จากนั้นรีเฟรชหน้าเว็บและตรวจว่าข้อความยังอยู่
- ลบข้อความทักษะทั้งหมดแล้วบันทึก ควรบันทึกค่าว่างได้
- ออกจากระบบ แล้วเข้าระบบครู ตรวจว่าหน้าครูถูกต้อง
- สร้างห้องพร้อมรายละเอียดงาน แล้วเปิดห้องตรวจรายละเอียด
- สุ่มกลุ่ม ตรวจว่าหมายเลขกลุ่มเรียงจากน้อยไปมาก
- ตรวจว่าการประเมินตนเองถูกปฏิเสธ

หมายเหตุ
- ฐานข้อมูลเป้าหมายคือ gg และโครงสร้างหลักต้องมี users, classrooms, enrollments, ratings, randomizationruns, classgroups และ groupmembers ตามที่ระบบใช้อยู่
- บัญชีครูต้องมี role = teacher; บัญชีนักเรียนต้องมี role = student
- นี่เป็นต้นแบบสำหรับใช้งานในเครื่อง/ทดสอบ ควรตรวจสอบความปลอดภัยเพิ่มเติมก่อนนำขึ้นอินเทอร์เน็ต


อัปเดตเพิ่มเติม: รายชื่อนักเรียนในห้องจะแสดงคอลัมน์ “ทักษะที่นักเรียนกรอก” สำหรับทั้งครูและนักเรียน โดยอ่านจากตาราง user_custom_skills หากยังไม่กรอกจะแสดง “ยังไม่ได้กรอกทักษะ”


ฟีเจอร์ผลการประเมิน (รุ่น 2026-10-26d)
- เปิดห้องเรียนแล้วกด 'ดูผลการประเมิน'
- ครูเห็นการประเมินทั้งหมด รวมผลจากนักเรียนและการประเมินที่ครูส่งเอง พร้อมผู้ประเมิน คะแนน และความคิดเห็น
- นักเรียนเห็นเฉพาะผลประเมินจากครู เพื่อไม่เปิดเผยการประเมินระหว่างเพื่อน
- ใช้ตาราง ratings เดิม ไม่ต้องเพิ่มตารางใหม่
